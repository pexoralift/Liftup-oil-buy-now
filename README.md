# Lift-Up Gold Landing Page

This version opens WhatsApp after the customer clicks **I HAVE PAID**.
The message is pre-filled with the order/shipping details.

Important: without WhatsApp API, the WhatsApp app/site opens with the message prepared,
but the customer must tap **Send**. The website cannot silently send the message.

GitHub Pages:
1. Upload `index.html` and `.nojekyll` to a public repository.
2. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
